# Oddgrain® | Lucky Kumar

A fresh, custom portfolio template for web design, full-stack development, Adobe work, photography, and copywriting.

## Structure
- `index.html` — portfolio homepage
- `projects/` — your original standalone website concepts, linked from Selected Work
- `assets/adobe/` — place your own Adobe artwork here
- `assets/photography/` — place your own photographs here

## Add Adobe work
Add files named `adobe-01.jpg` through `adobe-08.jpg` to `assets/adobe/`.

## Add photography
Add files named `photo-01.jpg` through `photo-08.jpg` to `assets/photography/`.

The gallery detects the matching image files automatically. You can use JPG or convert the code paths to WebP/PNG as needed.

## Before publishing
1. Replace `YOUR-EMAIL@example.com` in `index.html` with your real contact email.
2. Add your own work to the image folders.
3. Review project names/descriptions so they accurately represent the work.
4. Upload the contents of this folder to the root of your `oddgrain` GitHub repository.
5. Enable GitHub Pages from Settings → Pages → Deploy from a branch → `main` → `/(root)`.

This is a static site and does not require a build step.
